# KOJO Guide — внутренний справочник для сотрудников KOJO Coffee

Статическое PWA-приложение (обновляется через GitHub Pages) с чек-листами кофейни, инструкциями «Что делать если», сроками годности, заявкой в депо и стандартами сервиса.

## ✨ Новое в этой версии

- **7 учётных записей** вместо единого логина.
- **Прогресс чек-листов по каждому аккаунту** — каждый сотрудник видит только свой прогресс за сегодня.
- **Ежедневный сброс** — каждый новый день все отмеченные чекбоксы любых аккаунтов автоматически обнуляются.
- **Раздел «Контроль» (только для администраторов)** — показывает, сколько пунктов чек-листов каждый аккаунт выполнил за сегодня:
  - 📊 плитка «Контроль» на главном экране
  - 📋 кнопка в шапке приложения
- **Облачная синхронизация (jsonbin.io)** — включив её, прогресс сотрудников и раздел «Контроль» будут видны на нескольких устройствах одновременно (3 устройства и более).

## Как включить облачную синхронизацию (для «Контроля» на нескольких устройствах)

1. Зарегистрируйся на **https://jsonbin.io** (бесплатно).
2. Скопируй свой **X-Master-Key** (раздел «API Keys» в личном кабинете).
3. В приложении: войди под **администратором** → пункт **«Контроль»** → кнопка **«⚙️ Синхронизация»**.
4. Вставь **X-Master-Key** → нажми **«✨ Создать Bin автоматически»** (приложение само создаст Bin и запомнит его Bin ID).
   - Либо вставь готовые **Bin ID** и **Master Key** и нажми **«Сохранить»**.
5. Повтори то же на каждом устройстве, где нужен общий «Контроль».

После этого прогресс за сегодня у всех аккаунтов синхронизируется между устройствами онлайн. Без настройки облака приложение работает локально на устройстве (все аккаунты и админ-«Контроль» видны на том же устройстве).

## Структура проекта

```
├── index.html          — разметка приложения
├── css/styles.css      — стили
├── js/
│   ├── data.js         — контент (чек-листы, статьи, калькулятор)
│   ├── accounts.js     — учётные записи и роли
│   ├── state.js        — хранение данных (localStorage, per-account + дата)
│   ├── sync.js         — облачная синхронизация (jsonbin.io)
│   └── app.js          — логика приложения
├── sw.js               — service worker (PWA, офлайн)
├── build.ps1           — сборка единого dist/kojo-guide.html
└── dist/               — собранный single-file для рассылки
```

## Разработка

- Простое статическое приложение без сборки. Открой `index.html` в браузере или запусти локально.
- Сборка единого файла для рассылки телефоном/почтой:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат: `dist/kojo-guide.html`.

## Публикация (GitHub Pages)

Сайт раздаётся через GitHub Pages из ветки `main` (в корне). Пуш в `main` автоматически публикует новую версию.
